# PointOfSaleSystem 🚂

## 🎯 Project Objective
This is a one-user-only POS system designed for small shops. It handles the basics that are needed. A semester project of web engineering based on MERN Stack.

## 💻 Technologies Used
- MERN Stack
- MongoDB

## ▶️ How to Run
Run `npm install` and `npm run dev`.
